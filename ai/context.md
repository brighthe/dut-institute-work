# dut-institute-work 通用上下文（所有 AI 共享）

> 本文件是 `dut-institute-work` 对**所有 AI 助手**（Claude Code / Codex / Antigravity 等）通用工作规则的唯一来源。各工具的入口见根目录 [CLAUDE.md](../CLAUDE.md) 或 [AGENTS.md](../AGENTS.md)。

**仓库定位、内容去向与目录结构见 [README.md](../README.md)，不在本文件复述；本文件只规定写入时必须遵守的行为纪律。** 判断某类内容该放哪个仓库时，以 README 的内容去向表为准。

## 交流与写作

- **交流语言**：一律简体中文；代码、命令、专有名词保留英文。
- 文档正文使用简体中文，文件与文件夹名使用英文 kebab-case；会议纪要按 `YYYY-MM-DD-主题.md` 命名。
- 编辑中文 Markdown 时保持 UTF-8，修改后检查乱码和 Mojibake。

## 内容纪律

- **本仓库为 Public**：有依据且可公开的项目事实默认完整记录；账号密码、Token、VPN 密钥、私钥、个人隐私，以及未经授权公开再分发的源码、程序包、模型和内部附件不得写入。例外是用户明确授权的内部文档链接：仅可登记在 [hpc/artifacts.md](../hpc/artifacts.md)，不复制原件、正文或附件。
- **不替用户编造**：任务安排、时间节点、他人说过的话只写有依据的内容；拿不准时标注「待确认」。
- [hpc/plan.md](../hpc/plan.md) 是研究院 HPC 工作安排的**单一事实来源**：其他仓库（`heliangos/wechat`、`dut-postdoc`）只放指针，不复制正文；更新安排时只改这里。
- [hpc/log.md](../hpc/log.md) 是 append-only 进度日志：新条目只在文件头部追加，不修改历史条目。
- [hpc/artifacts.md](../hpc/artifacts.md) 是 HPC 交付物清单：记录文件名、版本、用途、归档状态和事实源；用户明确授权时可记录受控链接及登记时间，仍不保存原件、正文或附件。

## 内部系统的访问

研究院 GitLab 等内部系统**需连内网且需登录**，匿名访问只会被重定向到登录页。

- **AI 不持有、不索取、不代填任何凭据**。需要读取内部系统的内容时，由用户在自己已登录的浏览器中打开，或由能复用用户登录态浏览器会话的工具读取；AI 不自行登录。
- 各工具的可用读取方式不同，具体见该工具自己的入口文件（Claude Code 见 [../CLAUDE.md](../CLAUDE.md)）。
- 读到的内部内容**只用于当次判断**，按上文「内容纪律」处理：本仓只写脱敏结论，不整段搬运内部手册、源码或文档原文。
- 本机可复现的接入与排错步骤见 [../hpc/environment.md](../hpc/environment.md)。

## 跨仓库边界

具体去向以 [README.md](../README.md) 的内容去向表为准。执行时守住两条：

- 属于其他仓库的内容，本仓只留结论与一句话指针，**不复制正文**。
- **内容放错地方比暂时不写更糟**。遇到边界不清的材料，先提醒用户确认归属，不要先写了再说。

## Git

仅当用户明确要求 commit 或 push 时，读取并遵守 [git-workflow.md](git-workflow.md)。机器级 Git/SSH 配置由 `workstation` 仓库统一维护，本仓库只规定自身的提交与公开发布纪律。
