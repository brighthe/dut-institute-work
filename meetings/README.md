# 会议与讨论纪要

本目录保存大工项目相关**会议与讨论的纪要**：会上事实、形成的口径与行动项。一次会议一个文件，按 `YYYY-MM-DD-主题.md` 命名（主题用英文 kebab-case）。

纪要是**留证层**，不充当事实源：会上定下的安排进对应任务线 `plan.md`，进展与结论进该任务线 `log.md`，本目录只回答「这次会上说了什么、定了什么」。骨架见 [../schema/templates/meeting-note.md](../schema/templates/meeting-note.md)。

## 内容纪律

- **区分会上事实、形成的口径与行动项**，三者不混写。谁说的与本人的理解分开表述。
- **纪要来源必须写明**：现场记录、会后整理稿、自动纪要还是群聊回溯。不是亲历时尤其要写清楚，并保留原整理稿的核对状态（如「待参会各方核对」）。
- **不代替与会人补全立场**。未确认的表述标「待确认」，标注「待确认 / 待复核」的内容不作为既成事实被其他页面引用。
- **行动项落地后由对应任务线 `log.md` 承接，纪要本身不再改写**；纪要是当时的记录，不是滚动更新的状态板。
- 同一次会议涉及多条任务线时，纪要完整保留，各任务线 `log.md` 只摘取与自己相关的结论并指回本目录。
- 自动纪要中的术语按仓库约定统一（如 `SGCM` / `PetSC` 写作 SGSim / PETSc），并在纪要中说明做过术语校正。
- 会中出现的会议号、接入链接与凭据不记录；账号、密码、Token、VPN 密钥、私钥、个人隐私，以及未经授权公开再分发的源码、程序包、模型和内部附件不得写入。
