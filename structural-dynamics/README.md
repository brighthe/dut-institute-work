# 任务线 · 结构动力学软件模块验收

大连理工大学动力学软件模块采购项目（项目编号 **DUTAWZ-2026097**，采购人大连理工大学，代理机构大连机械设备成套有限公司）中 **C 包结构随机振动分析模块**的验收阶段任务线。合同判定口径：3 项 ★ 核心功能不接受负偏离，20 项 ▲ 性能指标逐条评议，其中 8 项要求提供算法原理描述与算例测试报告。

本任务线与研究院 HPC 任务线（[../hpc/README.md](../hpc/README.md)）相互独立：甲方均为大工体系，但合同、对接人与交付物互不相干。

## 内容纪律

- 合同判定口径（★ / ▲ 条款、偏离表结论）以招标文件与标书定稿为准，本目录只记结论与缺口，不改写条款原文。
- 材料状态分「有 / 缺失 / 待核实」三档，**待核实不得写成已有**；核实结果变化时更新清单并在 [log.md](log.md) 记一条。
