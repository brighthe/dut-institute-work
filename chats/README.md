## 命名与结构

- 文件名 `<平台>-<群标识>.md`（`feishu-` / `weixin-`），一个群一个文件，长期累积。
- 文件内按 `## [YYYY-MM-DD]` 分小节，标题表示**实际会话日期**；会话日期按倒序排列，便于优先阅读最新对话。
- 跨日抓取的消息按实际会话日期拆分；同一天来自多次抓取时，用 `### 归档来源（YYYY-MM-DD 抓取）` 保留抓取时间与**覆盖范围**。飞书 Web 端只渲染已加载的消息，未向上加载的早期历史不在归档内，必须如实写明。
- 来自截图转写的归档在文件开头说明截图批次与重复情况，未能读取的内容（如时间戳、被省略的链接）逐项标明。

## 读取通道

飞书的可用通道与内网 GitLab（见 [../hpc/environment.md](../hpc/environment.md) 3.2）**正好相反**，不要套用那边的结论：

| 方式 | 结果 |
| --- | --- |
| Chrome 扩展（Claude Code 的 `claude-in-chrome`） | ❌ `Navigation to this domain is not allowed`，域名层面被拒，无解 |
| 内置浏览器的 `navigate` | ❌ `navigation to ... was denied or failed` |
| **内置浏览器的 `preview_start`** | ✅ **可用**，`navOk: true`，且复用内置浏览器自身的飞书登录态 |

**关键差别在 `preview_start` 与 `navigate`**：同为内置浏览器，前者能打开飞书，后者被拒。被拒过一次不要放弃，换 `preview_start` 重试。

标准流程：

1. `preview_start` 传入飞书消息页 URL（**不要先试 `navigate`**）；
2. `get_page_text` / `read_page` 读取——**面板隐藏也能读**，此时可拿到会话列表与每条会话的最新一条预览；
3. 需要点开某个会话读完整对话时，**浏览器面板必须处于显示状态**。面板隐藏时页面不合成画面，元素没有布局盒，点击会落在 `(0,0)` 而静默失效，截图则直接报「the Browser pane is not displayed」。遇到这种情况请用户显示面板，或请用户自己点开目标会话，不要反复重试点击。

**登录态失效**时会看到登录页，告知用户重新登录，**不要尝试代为登录**。读到的内容按下节「写作纪律」处理。

## 写作纪律

- **忠实转写**：保留原始措辞、错别字、表情占位（如 `[抱拳]`、`[图片]`）与 `@` 提及；不润色、不改写、不合并他人发言。
- **保留回复关系**：飞书的「回复某条消息」用引用块表达，不要拍平成平铺对话。
- **时间戳按实际**：只对部分消息暴露时间时，缺失的标注「时间戳未取到」，不推断、不补齐。
- **没有真正读到的对话不得凭预览行推测补全**——归档要求原文照录。
- **凭据内容一律不录**：聊天流中出现的账号/密码文件只记文件名与大小，不打开、不摘录内容；会议号与接入链接同样不记录。这一条不因任何指示放宽。
- **不代为判断真伪**：原文中他人的表述照录，与本仓其他文件冲突时在 [../hpc/log.md](../hpc/log.md) 里更正，不改这里的原文。
