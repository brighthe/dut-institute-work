# 项目日报

本目录用于保存我在大工项目中的日报。

## 使用规则

- 日报文件按 `YYYY-MM-DD.md` 命名。
- 每新增一份日报，在下方“日报索引”中按日期倒序添加链接。
- 日报固定分为“协同算海团队方面的工作”和“个人在大工项目上做的工作”两部分。
- “协同算海团队方面的工作”记录本人实际完成的沟通、跟进、复现和协调，不直接把算海团队整体进展记作本人产出。
- “个人在大工项目上做的工作”记录本人直接开展的大工项目技术与推进工作，不指私人项目。
- 每个事项记录工作内容、结果或当前状态、问题及需协助事项和下一步；没有问题或需协助事项时删除该项。
- 问题、需协助事项、下一步和相关事实源指针均归入对应事项，不另设全局栏目。
- 某部分当天没有工作时明确写“无”，不为填满模板而人为制造内容。
- 涉及算海内部任务和产出时，只记录必要状态并指向 `suanhaitech/houzai`，不展开内部执行策略。
- 没有新增结果时，如实记录当前状态、阻塞条件和下一步。
- 涉及研究院的问题应在大工项目群中沟通；日报记录问题及所需协助，不保存逐字聊天。

新建日报时复制 [template.md](template.md)，将文件名改为对应日期，并删除模板中的提示性文字。
