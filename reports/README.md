# 项目报告

本目录统一承载大工项目的日报及后续可能形成的双周汇报、阶段汇报。

## 报告类型

| 目录 | 内容 |
| --- | --- |
| [daily/](daily/) | 项目日报；按“协同算海团队方面的工作”和“个人在大工项目上做的工作”两条工作线记录 |

未来需要双周汇报或阶段汇报时，可分别新增 `biweekly/`、`stage/` 等同级目录；本轮暂不创建。

## 内容边界

- 报告以有依据的项目事实为基础，不把团队整体工作直接记作本人完成的工作。
- “协同算海团队方面的工作”记录本人实际完成的沟通、跟进、复现和协调，不把算海团队整体产出表述为本人完成。
- “个人在大工项目上做的工作”记录本人直接开展的技术与项目推进工作，不指私人项目。
- 日报中的问题、需协助事项、下一步和相关事实源指针归入对应事项，不另设全局栏目；某条工作线当天没有内容时如实写“无”。
- 算海内部执行任务、产出及问题解决过程以 `suanhaitech/houzai` 为事实源；本目录只记录本人工作和必要指针，不复制内部执行策略。
- 账号、密码、Token、VPN 密钥、内部访问地址，以及未经授权公开再分发的源码、程序包、模型和内部附件不得写入。

## 日报写法

- 文件按 `YYYY-MM-DD.md` 命名；新建时复制 [daily/template.md](daily/template.md)，改名后删除模板中的提示文字。
- 每个事项记录**工作内容、结果或当前状态、问题及需协助事项、下一步**四项；没有问题或需协助事项时删除该项，不留空标题。
- 没有新增结果时，如实记录当前状态、阻塞条件和下一步，不为填满模板而人为制造内容。
- 涉及研究院的问题在大工项目群中沟通；日报只记录问题与所需协助，不保存逐字聊天。
