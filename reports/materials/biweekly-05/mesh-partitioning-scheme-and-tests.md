# 问题依赖网格分区 · 汇报

## 原始文件

- 原件：[网格分区方案与测试.html](网格分区方案与测试.html)

## 核心内容与结论

1. **核心问题与目标**（第 1–3 页）
   - 核心问题：在网格分区之前纳入约束（SPC/MPC/RBE）、单元类型与依赖信息，能否使分区更贴近实际计算负载？
   - 痛点：单元数均衡不等于计算负载均衡；固定约束（SPC）削减自由度，MPC/RBE 引入节点强关联，单元类型与跨区耦合不均导致各子区真实工作量严重失衡。
   - 总体目标：在满足硬分区要求（可行域）前提下，生成更贴近真实计算负载的分区方案。
2. **统一数学模型与可行域**（第 4–5 页）
   - 数学形式：在满足硬约束的可行域 $\mathcal{F}$ 内优化目标策略 $F_{\text{policy}}(x)$。
   - 硬分区要求（决定解是否可行）：
     - 单元唯一归属且分区非空：$x_{ip} \in \{0, 1\}, \sum_p x_{ip} = 1, N_p \ge 1$；
     - must-link（必须同区，如要求局部处理的 MPC/RBE 主从节点）、指定归属标签与 cannot-link（禁止共区）；
     - 容量上限：单元数 $N_p \le C_N$、分摊自由度 $D_p \le C_D$、局部唯一自由度 $L_p \le C_L$；
     - 连通性：每个子区在原网格对偶图上必须严格连通。
3. **负载代理指标与失衡度定义**（第 6–8 页）
   - 三种规模度量：单元数 $N_p$、分摊自由度 $D_p$（节点自由度按共享单元平均分摊，可加和，适合作为计算负载代理）、局部唯一自由度 $L_p$（包含边界共享自由度，更接近真实子域装配/存储规模）。
   - 失衡度指标：统一采用最大值与平均值之比，即 $I_N = \max N_p / \bar{N}$、$I_D = \max D_p / \bar{D}$、$I_L = \max L_p / \bar{L}$。
   - 软优化目标：最坏材料混合度、总体材料混合、边界接口代价与跨区耦合，采用字典序或加权策略在可行解中择优。
4. **两阶段求解与独立验收流程**（第 9–10 页）
   - 算法流程：输入检查 → METIS 生成初始候选 → 约束保持的局部搜索（move / swap / patch 算子修复容量、连通性与 must-link）→ 在原始真实模型上进行独立验收判定。
   - 判定状态分为三类：`feasible`（可行）、`infeasible_proven`（证明无解）、`no_feasible_found`（未找到可行解）。
5. **典型约束模型验证**（第 11–13 页）
   - 2D 平板（带局部密集 SPC 约束，4 Part）：单元数均衡方案的 $I_D = 1.10$，而考虑约束后降至 $1.05$，未固定自由度分布更平坦。
   - 焊接多体结构（圆筒 8 Part）：满足 must-link 与连通性硬约束，单元数与分摊 DOF 失衡均严格控制在 1.10 以内。
6. **MPC 强约束模型的瓶颈与策略权衡**（第 14–17 页）
   - 经典 MPC 尖峰现象：在 METIS 70 Part 单元均衡基线下，单元失衡仅 1.10，但分摊自由度失衡高达 **5.3871**，局部自由度失衡高达 **4.7149**。原因在于 MPC 主从约束聚类形成局部极高自由度密度，且必须同区，在 70 Part 切分下单区不可再拆。
   - 策略对比与放宽硬上限：
     - 若严格限制 $I_N \le 1.10$，自由度失衡无法消除；
     - 放宽单元数限制，转向局部自由度优先并引入硬上限：在 70 Part 下，将局部 DOF 硬上限设为 1.15，成功求得可行解（$I_L = 1.149987$），分摊失衡从 5.39 压降至 1.48，显著削平了计算负载尖峰。
7. **真实 SGSim 有限元全流程与性能验证**（第 18–24 页，全新实测）
   - 在真实工程算例（如 50w-mix23d、100w-mix23d）上直接接入 SGSim 进行端到端有限元求解，验证自由度代理与真实耗时/内存的关系：
     - **正确性**：260 组有限元数值结果与原生求解逐值比对一致，退出码 0，结果导出成功；
     - **单元装配与刚度计算收益**：在 50w 模型（6 MPI）下，新分区显著均衡了各 rank 的装配与刚度计算时间（max/avg 从 2.298 降至 1.064，最大刚度耗时从 21.5s 降至 9.8s）；
     - **全流程用时与内存**：
       - 50w 模型在 6 MPI 下全流程墙钟耗时**下降 11.82% ~ 12.87%**；
       - 100w-mix23d 模型（6/8 MPI）全流程耗时变化在 -0.15% ~ +2.94% 之间（基本持平），但**总峰值内存（PSS）显著下降 5.7% ~ 6.9%**；
     - **收益边界**：当前支持“特定模型显著获益”，尚未达到“普遍加速、普遍降内存”；当矩阵求解（如 CPARDISO 数值分解）占主导时，装配阶段的提速对总全流程的拉动会被稀释。
8. **阶段性结论与后续方向**（第 24–25 页）
   - 阶段结论：完成了从数学建模、约束处理、局部搜索到真实有限元求解的全链路闭环验证；证明了 DOF 负载代理在刚度装配与内存削峰上的直接有效性。
   - 核心挑战与权衡：
     - **收益不普遍**：不同模型、不同求解阶段对分区的敏感度不同；
     - **均衡 vs 接口 vs 形状的三方冲突**：追求绝对的自由度均衡可能导致边界接口边数增加或子域形状变差，进而增加求解器通信或收敛负担；
     - **下一步**：结合代数求解器（BDDC）的收敛性与通信特征，进一步联合优化子域形状与接口代价。
