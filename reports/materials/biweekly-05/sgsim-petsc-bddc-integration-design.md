# SGSim PETSc BDDC 集成设计

## 核心内容与结论

1. **数据需求**：现有流程由 FEMSolve 完成装配和约束处理，之后只把全局 $A$、$b$ 传给代数模块。BDDC 还需要：
   - 约束处理后的子域矩阵 $K_i$；
   - 局部—全局映射 $R_i$，满足 $A = \sum_i R_i^{*} K_i R_i$；
   - MPI 方程布局与界面信息。
2. **子域矩阵的两种构造方案**：
   - 方案一：从全局矩阵中提取 $R_i A R_i^{*}$，再分配共享条目。实现较简单，但分配方式会影响预条件质量；MPC / RBE 消元产生的新耦合需要额外处理。
   - 方案二：从单元贡献装配 $\hat{K}_i$，再做一致的约束变换 $K_i = T_i^{*} \hat{K}_i T_i$。数学一致性明确，但实现工作更多。原件同时说明，数学一致性不直接保证收敛速度。
   - **原件没有选定方案**，后文一律以「选定方案」代称。
3. **职责划分**：
   - 有限元侧负责形成方程、处理物理约束，并由 SGFem 恢复结果。
   - 代数模块以全局 $A$ 作为 Amat、以子域 MATIS 作为 Pmat，通过 KSP / PCBDDC 求解。
4. **接入策略**：
   - FEMSolve 现有接口只传 $A$、$b$，当前又无法修改其源码，所以仅切换代数求解器，两种方案都接不进去。
   - 现阶段：在 Main 增加 BDDC 分支，调用新增的分析入口，由它组织数据准备、求解与结果恢复。
   - 后续：把选定方案合入 FEMSolve，并删除 Main 分支和重复的流程组织。
5. **修改范围**：
   - 涉及矩阵提取接口（方案一）、装配与约束接口（方案二）、代数模块（MATIS + BDDC）、新增分析入口、Main、FEMSolve 六处。
   - 原有求解路径保留；本次不扩展网格划分模式，也不扩展进程内子域组织策略。
