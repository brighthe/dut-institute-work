# 算海团队第五次双周会议预计产出

会议时间：2026.10.9

## 三项预期产出

### 01 面向 BDDC 和异构计算的结构感知分区与任务划分方案

汇报人：陈康

回答数据和计算任务应该如何组织，形成面向典型算例的分区与任务划分初步方案。

- 覆盖局部子域、局部—全局自由度映射、接口、约束和粗空间所需结构信息。
- 分析分区对单元计算、约束处理、局部矩阵、通信、内存和收敛的影响。
- 明确候选策略、评价指标和后续验证路径。

### 02 面向典型算例的迭代法性能基线与瓶颈分析

汇报人：胡凯

回答性能问题究竟发生在哪里，建立统一口径下可复现的基线和优化优先级。

- 围绕 PETSc Krylov 方法及 BDDC 等预条件器，统一编译、运行和测试条件。
- 关联单元计算、约束处理、分区、分布式矩阵与向量、数据库五个方向。
- 形成分阶段计时、收敛、内存、负载和通信数据及瓶颈归因。

### 03 面向多后端与 GPU 的异构并行 Demo 优化与可行性验证

汇报人：宋维豪

回答新的数据组织和计算架构能否在 CPU/GPU 环境中运行并带来实际收益。

- 扩展 TensorFem 闭环，验证张量化计算、并行任务组织和 CPU/GPU 后端切换。
- 在稳定 GPU 环境下补充多线程、多 `rank` 和 GPU 路径的正确性与性能对比。
- 分析数据传输、显存驻留、批量计算及显式矩阵与 `matrix-free` 边界。

## 三个任务之间的关系

- **01 · 上游结构**｜分区与任务划分：提供子域、接口、映射和任务布局等上游结构基础。
- **02 · 性能证据**｜性能基线：测量阶段耗时和资源表现，定位瓶颈并评价优化是否有效。
- **03 · 架构验证**｜异构并行 Demo：复用结构和数据结论，验证并行与 GPU 架构能否落地。

**共同基础**：三项任务并行推进，共享典型算例、统一环境、正确性标准、性能统计口径，以及局部矩阵、自由度映射、接口和分区数据定义。

结构分析 → 任务组织 → 性能测量 → 架构验证 → 反馈优化
