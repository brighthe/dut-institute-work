# SGSim × TensorFem 异构有限元计算进展

## 来源

- 作者：宋维豪（算海）。原件未署名，2026-09-28 经用户确认。
- 发出时间与渠道：2026-09-28，飞书算海内部群。
- 形式：12 页单文件网页幻灯片，3.2 MB。页脚注明「基于 2026-09-28 已归档实测结果」。

## 核心内容与结论

1. **GPU 路径**
   - 之前的做法：单元刚度 Ke 在 GPU 上算完后，拿回 CPU 装配。
   - 现在的做法：数值装配、PETSc CUDA 求解和反力 / 应力计算都在 GPU 上完成，最后把结果交回 SGSim 输出 HDF5。
   - 仍在 CPU 上的环节：数据库读取、数据组织、COO 索引和 HDF5 写出。
2. **MPI 多进程**
   - 各 rank 通过 Partition 和 Service 取到自己分区的数据，完成单元计算后，一起做 PETSc 分布式求解。
   - 已在 1、2、4、8 个进程上运行，但只在单节点、单 GPU 上验证过。
3. **算例**：SOL 101，一端固定、另一端加均布压力，分两档规模：
   - 中型 Tet：96,000 个四面体，52,920 个自由位移 DOF；
   - 30k GRID Tet：165,888 个四面体，90,000 个自由位移 DOF。
4. **正确性**
   - 共 42 组首轮结果与单进程直接法逐值对照，全部通过。
   - 最大相对 L2 误差：位移 7.18e-11，反力 3.15e-11，应力 1.72e-11。
   - 这 42 组是选定的首轮结果，重复运行的结果没有逐一比较。
5. **性能**
   - CUDA 单进程最快：中型 Tet 3.621 s，30k GRID Tet 5.248 s。
   - 但 CUDA 路径增加进程反而更慢。8 个 rank 共用一张卡时，30k GRID Tet 的加速比只有 0.67×，两个算例的并行效率约 8%。
   - CPU 直接法 8 进程的加速比为 1.50×（中型）和 1.66×（30k GRID）。
   - 从 1 进程到 8 进程，显存由 1,660 MiB 增至 2,770 MiB（中型），由 2,674 MiB 增至 3,976 MiB（30k GRID）。
6. **结论与边界**
   - 结论：GPU 计算链路已经打通；多进程结果正确；加速比、效率、时间和内存都已量化。
   - 验证范围：SOL 101、CTETRA4、MAT1 / PSOLID、PLOAD4 / SPC、基本坐标系，单节点单卡。
   - 代码同时支持 CHEXA8，但本轮只演示了 CTETRA4。中间数组没有逐项对照。
