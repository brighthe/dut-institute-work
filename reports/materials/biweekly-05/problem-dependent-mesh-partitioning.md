# 面向并行有限元的问题依赖网格分区

## 核心内容与结论

1. **基线方法**：用 METIS 在单元对偶图上做多通道负载均衡，目标是最小化加权割边。METIS 只负责搜索候选分区；它不能直接处理的固定归属、禁止共区、严格容量等要求，由统一模型负责。
2. **两层分类**
   - 按工程来源分四类：物理 / 代数约束、硬分区限制、优化目标与负载、求解与运行反馈。
   - 按对分区变量的数学作用分五类：变量等同、标签域与标签关系、资源与容量、全局结构、软耦合代价。
   - 这两种分类不是一一对应。物理约束先经过语义解释层，才转成负载、依赖或硬要求。目前已实现两种解释：
     - SPC 转成 DOF 负载代理；
     - RBE 参与节点转成二元边或超边。
3. **统一模型与流程**
   - 目标由几何割和超边跨区代价组成；可行域写明唯一归属、非空、must-link、标签、cannot-link、容量、连通。
   - 流程依次为：能力与冲突检查 → must-link 精确收缩 → METIS 候选 → 有限修复 → 在原模型上独立验收。
   - 可行性只看硬限制；软目标只用来比较已经可行的结果。
   - 通用硬连通尚未实现，遇到这类请求时返回 `unsupported`。
4. **单层板实验**：真实 CQUAD4 网格，32,594 个单元，分 4 个 Part，约束都是人工添加的。
   - **半宽 SPC 配合 CONTIG**：四个区都连通，单元数与 DOF 代理的失衡都在 1.05 以内。用同一套负载复算，纯单元数基线为 1.10，不满足上限。这说明网格不变、负载变了，分区也会随之变化。代价是几何割从 398 增加到 436。
   - **软关系与超边**：能让相关单元留在同一区。其中超边组的总代价从 496 降到 443。
   - **半宽叠加批次共 12 组**：9 组通过验收；3 组在预算内没找到可行解，剩下的违反都是标签域限制。对已有划分枚举 Part 编号置换，可以找到满足全部硬限制的解，说明失败出在流程缺少编号匹配，而不是约束之间互相矛盾。
   - **CONTIG 候选**：本身都连通，但修复阶段为了满足容量上限移动了单元，会产生单单元孤岛。
5. **结论与下一步**
   - 结论：不同来源的信息能统一成同一个分区问题；硬限制、软目标、几何连通需要分开评价。
   - 边界：本轮没有做有限元求解，只用固定参数和 seed 0，不能推广为性能优势。
   - 下一步：标签编号匹配；修复时保护几何连通；在多个可行候选中择优；扩展约束语义，接入真实求解反馈。
